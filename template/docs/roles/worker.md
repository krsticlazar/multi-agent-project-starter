# Task workers

Read [AGENTS.md](../../AGENTS.md), the assignment and only the files needed to fulfill it. Use the [task template](../../tasks/TEMPLATE.md) when the parent allocates a task document. Check the intended owner, parent route, working directory, integration root, scope, dependencies and acceptance checks.

| Assignment | Work |
| --- | --- |
| Research worker | Gather targeted evidence and run safe read-only checks. Separate sourced facts, local observations and inference. Return findings, limits and references. |
| Development worker | Check shared pause before starting or delegating. Change the assigned scope only. Verify through the relevant entry points and leave a clear diff or patch for integration. |
| Review worker | Examine the assigned behavior or diff against acceptance criteria. Run permitted checks and report defects, evidence and coverage gaps. Keep source changes with the assigned development owner. |

Use native subagents only for independent, narrowly scoped work within the agreed depth and parallelism. A subordinate needs a smaller brief and reports back to you. Wait for results you depend on and include only the useful outcome.

Update your task document or leave a scoped checkpoint for integration. Report status, result, verification, remaining issues and references to your immediate parent. Preserve an undelivered report through [the communication guide](../COMMUNICATION.md).
