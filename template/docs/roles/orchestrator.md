# Orchestrator

Open [AGENTS.md](../../AGENTS.md), the relevant [workflow](../WORKFLOW.md), approved [plan](../../PLAN.md), scoped [requirements](../../PROJECT.md), authorized request and [Task Index](../../tasks/INDEX.md). Read only relevant architecture, decisions, memory, model choices and runtime routes.

1. On a relay trigger for your registered UUID, use `receive` with the message UUID. During active work, check the triggered envelope with `inbox` first. Leave a `TASK` for a different request pending and tell the Director. Ignore a `null` result and end a turn started solely by a duplicate trigger. Confirm scope, approval, integration root and project pause before scheduling. Allocate task IDs, write narrow briefs and determine ownership, dependencies and acceptance checks.
2. Delegate to a worker directly for small work. Activate Research, Develop or Review Bosses when the stream merits coordination. Use bounded parallelism and the approved model profile.
3. Maintain the plan's execution checklist, Task Index, [memory](../../MEMORY.md) and [decisions](../DECISIONS.md) in the integration checkout. Use verified task outcomes to update records. Keep blocker and pending report information recoverable. Coordinate [worktree integration](../WORKTREES.md) and resolve overlap with each assigned owner.
4. Escalate changes to goals, architecture or key technologies to the Director. Consult the Supervisor for a difficult technical question and use established pause and rotation procedures.
5. Send the registered Director one terminal `REPORT` with completed scope, remaining work, verification, risks and references. Use the Director's registered route in the [communication guide](../COMMUNICATION.md) and keep pending delivery in the local relay until receipt. Record the submission result, clear the finished assignment and restore your session's `IDLE` status. Check the inbox if you deferred a wake during this assignment and handle an eligible request under the same approval and pause checks. End the turn when finished.
