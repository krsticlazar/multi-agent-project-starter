# Idea queue

The Director maintains this backlog of independent user requests. A queued item needs explicit user approval before execution.

| Request ID | Date | Idea or change | Acceptance notes and dependencies | Status |
| --- | --- | --- | --- | --- |

Use `QUEUED`, `APPROVED`, `STARTED` or `WITHDRAWN`. When the active request finishes, report the result and surface related queued requests for the user to choose from.
